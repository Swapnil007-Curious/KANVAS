\section{Limitations}
\label{sec:limitations}

The study uses one trace and a single time-ordered split. The telemetry describes neighbouring jobs, a proxy for the task's own conditions. The filters keep \V{data.full.share} of labelled tasks and raise the failure rate to \V{data.full.rate}, so the population is selected. The features contain nothing about the user's code or configuration, a common cause of failure~\cite{jeon2019philly}. \kaam{} has no interactions, the validation grids are small, and the EBMs were fitted on the original sample only, for compute reasons.
