\section{Evaluation Protocols}
\label{sec:protocols}

A protocol file fixed the protocols, grids, metrics and tests before any model was trained on the new data. It is self-registered: its SHA-256 is recorded with every read of test labels, which go through a single logged function, and no test label was read before every model had been fitted. Four changes made before that point are listed in the full version. Two affect the comparisons: early stopping on validation log loss was replaced by early stopping on validation AUC, because the label shift of the time-ordered split made an untrained network look best by log loss; and the EBMs were fitted under the protocols on the original sample only. The original sample was already analysed in the first version with the same random split seeds, so its results are not confirmatory.

\emph{Random}: \V{prot.random.nsplits} stratified \V{prot.frac} splits; the \emph{canonical} split is the one with seed \V{prot.canon}. \emph{Time-ordered}: the earliest \V{prot.time.train} of tasks by start time train, the next \V{prot.time.val} validate, the last \V{prot.time.test} test (the final \V{full.split.time.t.testdays} days of the telemetry span); test tasks are \emph{known-user} if their user has a training task, \emph{new-user} otherwise. \emph{User-grouped}: \V{prot.folds}-fold \texttt{StratifiedGroupKFold}~\cite{pedregosa2011sklearn} by user (seed~0), with validation users drawn from the remaining users by a second grouped split. \emph{Leave-dominant-user-out}: the canonical random split after removing User~1, or Users~1 and~4, where users are numbered by their task count.

Hyperparameters are chosen per split by validation ROC-AUC. We report test ROC-AUC (primary), PR-AUC (average precision), the Brier score and the expected calibration error (ECE, \V{stat.bins} bins)~\cite{guo2017calibration}; PR-AUC and the Brier score are in the full version. Comparisons with \kaam{} use a paired bootstrap~\cite{efron1993bootstrap} with \V{stat.nboot} resamples of the test tasks (of the users under the grouped protocol), with the fitted models held fixed, so the intervals do not include training or fold variation. $p$-values are Holm-adjusted~\cite{holm1979simple} within each protocol (three comparisons on the full trace, five on the original sample); ``not significant'' means an adjusted $p\geq$\V{stat.alpha}.
