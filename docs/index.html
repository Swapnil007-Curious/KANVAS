KANVAS GPU job failure prediction you can read

Will this job on a shared GPU cluster fail? A 151-parameter additive model, trained on 377,870 tasks from Alibaba's 2020 GPU cluster trace, gives a failure probability and splits it exactly into one contribution per input, each read off its own curve.

Paper (PDF) Code

Limitation: do not use this model for new users. It works best for users whose earlier tasks are in its training data. With whole users held out, every model in the study scores far lower (test ROC-AUC 0.57 to 0.64, near chance on some groups of users), and every model scores only about 0.6 on a later period of the trace, even for known users. Why: one contribution per input

Each bar is how far that input moves the failure log-odds away from the average training task. The bars add up exactly to the prediction. Select an input's name to see its curve.

    Each curve is one input's learned effect on the failure log-odds, measured against the average training task (the zero line). The dot is the current input. Click or drag on a curve, or focus it and use the arrow keys, to change that input.

    Grey edges mark the outer 5% of training tasks on each side, where the curve rests on less data. The strip along the bottom shows how training tasks are spread. Small circles are the values discrete inputs take in training. Inputs outside the shown range are clipped to its ends before the model sees them.

    A random split scatters each user's tasks across training and test, so a model can score well by recognising heavy users it has already seen, while a user-grouped split keeps all of a user's tasks on one side, which is the situation the model faces with a new user.
